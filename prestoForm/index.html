2. Customizing the Reconstruction Paramters


Each reconstruction method comes with a set of options, such as the temporal resolution or the paleoclimate proxies used. You can choose to use:

1) the default paramters, which will produce a reconstruction similar (possible changes due to availability of new data) to the orignal, published data,

2) the online configuration editor, which provides short descriptions and possible options of each paramter, or

3) the manual paramter upload option, for expert use.


3. Exploring the Results


After you submit your reconstruction choices, you will receive an email with a link to the results, including both data and visualiztion(s). The readme file will provide some details on how to use and interpret the results.
