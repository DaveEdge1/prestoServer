<p style="font-size:15px">To create a Temperature 12k Composites reconstruction, adjust the options below and click "submit." You will recieve an email when your reconstruction is done.
<br>
<br>
For more information about each of the options, mouse over the question mark icons or see <a href="https://doi.org/10.1038/s41597-020-0445-3" target="_blank">Kaufman et al. 2020</a> for more details. Default values will produce a reconstruction similar to the one in Kaufman et al., 2020. If you are unsure what an option does, leaving it at its default value is a good choice.<p>
